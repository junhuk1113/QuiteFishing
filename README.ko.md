# 🌟 기능
## 🎯 다른 사람의 낚시찌 소리 제거
다른 플레이어의 낚시찌 소리에 더 이상 방해받지 마세요! 자신의 낚시찌 소리를 제외한 모든 낚시찌 소리를 음소거합니다.

## 🔊 낚시찌 소리 고정
이제 낚싯줄을 너무 멀리 던져 입질을 놓칠까 봐 걱정하지 마세요. 거리에 관계없이 자신의 낚시찌 소리가 항상 일정한 볼륨으로 들립니다.
